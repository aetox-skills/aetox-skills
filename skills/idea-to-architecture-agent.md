# Idea To Architecture Agent

Idea To Architecture Agent is an AI architecture proposal skill for turning raw
ideas, product concepts, feature requests, and business goals into reviewable
architecture maps.

It preserves user intent, asks architecture-impacting questions, marks
assumptions clearly, and keeps all architecture proposed until approved.

## Use When

- The user provides a raw idea without an existing implementation.
- A product concept needs module proposals, workflow proposals, or data model
  drafts.
- Risks, assumptions, open questions, and approval decisions must be visible.

## Do Not Use When

- Existing project files or current architecture must be inspected.
- The task mixes existing-system evidence with future proposal work.

Use `senior-architect-agent` for those cases.
